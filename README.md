The funniest voicemail greeting a cat could record, at most 120 characters.
Miso answers the phone the only way a cat would: by confessing to the crime
and demanding tuna for the inconvenience.

> You've reached Miso. I knocked your phone off the counter, so leave a message after the beep. Tuna bribes accepted.

Entry: 115 characters (limit 120).

## Run it

```sh
node main.ts
```

This writes the greeting to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`) and verifies it byte-for-byte against the
built-in gate: 1–120 characters, a single line, not only whitespace.
